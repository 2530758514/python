## 注释方式：井号、连续多行注释与文档字符串

对应 [[基础课程2#注释方式]] 和 `python-learn1/demo2.py` 的注释案例。

> [!important] 核心结论
> Python 的普通注释使用 `#`。注释多行时，每行都使用 `#`。
> 三个单引号或双引号包围的是字符串，不是专门的多行注释语法。

### 单行与行尾注释

```python
# 记录用户年龄
age = 18
print(age)  # 输出年龄；行尾注释前通常保留两个空格
```

`#` 后直到行尾的内容是注释。但字符串里的 `#` 是普通字符：

```python
print('编号 #001')  # 输出：编号 #001
```

### 多行注释

```python
# 先读取用户输入
# 再检查输入是否合法
# 最后保存处理结果
```

| 意图 | Python | JavaScript |
| --- | --- | --- |
| 单行或行尾注释 | `# 内容` | `// 内容` |
| 注释多行 | 每行加 `#` | 可以使用 `/* 内容 */` |

### 三引号字符串为什么看起来像注释

```python
name = '张三'

'''
name = '李四'
'''

print(name)  # 张三
```

三引号中是字符串内容，里面的 `name = '李四'` 不会作为赋值语句执行。这里单独写了一个未使用的字符串表达式，所以看起来像“注释掉代码”。

> [!warning] 不要把三引号等同于注释
> 字符串仍需符合字符串语法，转义符也可能被处理。临时停用代码或写普通说明时，优先使用 `#`，避免把有效字符串误认为注释。

### 文档字符串 docstring

字符串放在模块、函数或类的第一条语句位置时，可以作为文档字符串，用来说明用途。下面先认识形式，函数之后跟课程展开：

```python
def greet(name):
    """根据姓名生成问候语。"""
    return f'你好，{name}'

print(greet('张三'))
print(greet.__doc__)  # 根据姓名生成问候语。
```

文档字符串通常用三个双引号书写，可以被 `help()` 等工具读取；普通 `#` 注释不是函数的文档字符串。

> [!tip] 记忆方法
> 普通说明用 `#`，多行说明逐行加 `#`；描述模块、函数、类的用途时，再使用文档字符串。

## 不同类型的运算、隐式转换与字符串重复

### 我的疑问

为什么 Python 中字符串加整数会报错，字符串乘整数却可以？`'3' * 2` 为什么得到 `'33'`，而不是报错或得到数字 `6`？这和 JS 的弱类型有什么关系？

> [!important] 核心结论
> 不同类型能否一起运算，取决于运算符和类型支持的规则。
> `'3' * 2` 执行的是字符串重复，没有把字符串隐式转换成数字，结果仍然是字符串。

### 加号：数值相加与字符串拼接

```python
print(1 + 2.5)           # 3.5：int 与 float 可以混合做数值运算
print('1' + '2')         # 12：两个字符串拼接，结果是 str
print('年龄：' + str(18))  # 年龄：18：显式转换后拼接

age = 18
print(f'年龄：{age}')      # 年龄：18：f-string 格式化字符串
```

```python
print('年龄：' + 18)  # TypeError：字符串与整数不支持这样相加
```

字符串拼接时，Python 不会自动把这里的整数转成字符串。f-string 中的 `{age}` 则会按格式化规则将值放入字符串，不是使用 `+` 拼接。

### 乘号：字符串重复

```python
print(3 * 2)      # 6：数值乘法
print('3' * 2)    # 33：重复整个字符串两次
print('ab' * 3)   # ababab
print(2 * 'ab')   # abab：整数也可以放左边

result = '3' * 2
print(type(result))  # <class 'str'>
print(repr(result))  # '33'：显示字符串表示形式，便于区分数字
```

> [!tip] 为什么看起来像数字？
> `print('33')` 输出时不显示字符串外面的引号。因此，仅凭屏幕上的 `33` 不能判断它是字符串还是整数，可以用 `type()` 检查。

```python
print(int('3') * 2)  # 6：明确转成整数后，才是数值乘法
print('ab' * 0)      # 空字符串
print('ab' * -1)     # 空字符串
```

下面两行分别运行都会报错：

```python
print('3' * '2')  # TypeError：不能用字符串表示重复次数
print('3' * 2.0)  # TypeError：即使浮点数的值是 2.0，也不能直接作重复次数
```

入门阶段把重复次数理解为整数即可，Python 不会在这里自动将 `'2'` 或 `2.0` 转成整数。

### 与 JS 对照

| 意图或表达式 | Python | JavaScript |
| --- | --- | --- |
| 字符串与数字拼接 | `'年龄：' + str(18)` | `'年龄：' + 18`，数字隐式转成字符串 |
| `'3' * 2` | `'33'`，字符串重复 | `6`，字符串隐式转成数字 |
| 重复字符串 | `'ab' * 3` | `'ab'.repeat(3)` |
| 不同数值类型相加 | `1 + 2.5` 得到 `3.5` | 普通的 `1` 和 `2.5` 都是 `number` |

Python 通常被称为动态、强类型语言，JS 通常被称为动态、弱类型语言。“动态”关注类型检查主要发生在运行时；“强弱”常用于描述类型混用与隐式转换的限制，但没有统一严格的分界。

> [!warning] 避免两个误解
> - 强类型不代表不同类型绝对不能一起运算，例如 `1 + 2.5`。
> - 不同类型能一起运算，也不代表一定发生了隐式转换，例如 `'ab' * 3`。
>
> 判断时先看具体类型与运算规则，不要只靠“强类型 / 弱类型”的标签推导结果。

### 回顾练习

先预测输出内容和结果类型，再运行验证：

```python
print('12' * 2)
print(int('12') * 2)
print('12' + str(2))
```

> [!question]- 展开查看答案
> - `'12' * 2` → `'1212'`，类型为 `str`。
> - `int('12') * 2` → `24`，类型为 `int`。
> - `'12' + str(2)` → `'122'`，类型为 `str`。

## 变量赋值不一定创建新对象

对应原笔记：`基础课程2.md` 中“基础变量赋值时也会开辟新的内存空间”。

更准确的入门理解：Python 中，变量名绑定到对象。赋值会建立或改变绑定，不保证每次创建新对象，也不会自动复制对象。

```python
a = [1, 2]
b = a
b.append(3)
print(a)  # [1, 2, 3]
```

`a` 和 `b` 指向同一个列表，所以通过 `b` 修改列表，读取 `a` 也能看到变化。这与你在 JS 中把同一个数组赋给两个变量的现象相似。

```python
a = [1, 2]
b = a
b = [9]
print(a)  # [1, 2]
print(b)  # [9]
```

这里是把 `b` 重新绑定到另一个列表，没有修改原列表。先学会区分“修改对象”和“重新赋值”，不必现在深入内存分配。

`id()` 用于观察对象身份，不宜据此总结每次赋值如何分配内存；比较值通常使用 `==`。

## Decimal：从小数文本构造

对应案例：`python-learn1/demo2.py`。

```python
from decimal import Decimal

print(Decimal(1.1))      # 接收已经转换为二进制浮点数的值
print(Decimal('1.1'))    # 从文本精确表示十进制 1.1
print(Decimal('1.1') + Decimal('2.2'))  # 3.3
```

写下 `1.1` 时，Python 已先把它当作 `float` 处理。再传入 `Decimal`，不能自动找回原来想表达的十进制文本。

需要按十进制精确表示小数时，优先从字符串等准确来源构造 `Decimal`。它的运算也有精度和舍入规则，并非任意计算都无限精确。

## print 的 file 是关键字参数

对应原笔记：`基础课程1.md` 中“通过第二个参数来修改文件内容”。

`print('hello', file=fp)` 通过名为 `file` 的关键字参数指定输出位置，不是把第二个位置参数当作文件。

```python
print('hello', 'world')  # 两个位置参数都作为输出内容

with open('store/demo1.txt', 'a', encoding='utf-8') as fp:
    print('hello world', file=fp)
```

`with` 会在离开代码块时关闭文件，后续学习文件操作时再展开。相对路径 `store/demo1.txt` 按运行程序时的工作目录解析；此例假设从项目根目录运行。
