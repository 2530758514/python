> [!important] 本课先记住这几件事
> - `input()` 返回字符串；需要数字运算时显式转换。
> - 赋值绑定对象，不代表复制对象。
> - `//` 向下取整，不是简单删除小数部分。
> - `==` 判断值是否相等，`is` 判断是否同一个对象。
> - `and` 对应 JS 的 `&&`，`or` 对应 `||`；它们不一定返回布尔值。
> - `in` 判断成员关系，不等于 JS 的 `in`。

## 1. input：先获得文本，再决定如何使用

```python
a = input('请输入第一个整数：')  # 假设输入 1
b = input('请输入第二个整数：')  # 假设输入 2

print(type(a), type(b))  # <class 'str'> <class 'str'>
print(a + b)            # 12：字符串拼接
print(int(a) + int(b))  # 3：整数相加
```

提示语只是说明，不会限定用户输入的类型。按回车提交输入时，行尾的换行符不会保留在返回值中。

```python
print(int('12'))       # 12
print(float('12.5'))   # 12.5
print(int(12.5))       # 12：浮点数转换为整数，向零截断
# int('12.5')          # ValueError：这不是合法的整数字符串
```

> [!warning] 转换不保证成功
> 输入空字符串、`abc` 或把 `'12.5'` 直接传给 `int()` 都可能导致 `ValueError`。之后学习 `try/except` 再处理非法输入；现在先知道报错原因，不用提前掌握异常处理。

## 2. 链式赋值：绑定同一个对象，不是连续复制

原笔记中的“连续复制”建议改为“右侧表达式求值一次，再绑定到多个目标”。

```python
a = b = c = 10
print(a is b, b is c)  # True True

a = 20
print(a, b, c)        # 20 10 10
```

最初三个名字绑定到同一个整数对象。`a = 20` 改变的是 `a` 的绑定，不会把原来的整数改成 20。

更容易出问题的是共享可变对象，例如列表：

```python
a = b = []
a.append('Python')
print(b)  # ['Python']：a 和 b 指向同一个列表

# 如果需要独立的列表，分别创建
a = []
b = []
a.append('Python')
print(b)  # []
```

> [!tip] JS 对照
> JS 中让多个变量引用同一个数组，也会看到类似的共享修改。但不要用 JS 的变量声明规则推导 Python；在 JS 中应先声明变量，避免通过链式赋值意外给未声明的名字赋值。

## 3. 增强赋值与除法

`+=`、`-=`、`*=`、`/=`、`//=`、`%=`、`**=` 都是增强赋值。数值入门时可以用 `a += 1` 类比 `a = a + 1`，但对可变对象，两者不保证行为完全相同。

你的数值案例完整计算如下：

```python
a = 10
a += 10  # 20
a *= 3   # 60
a += 7   # 67
a /= 2
print(a)        # 33.5，不是 32.5
print(type(a))  # <class 'float'>
```

### /、// 与 int 的差别

| 表达式 | 结果 | 含义 |
| --- | --- | --- |
| `7 / 2` | `3.5` | 普通除法 |
| `8 / 2` | `4.0` | 两个整数使用 `/`，结果仍是浮点数 |
| `7 // 2` | `3` | 商向下取整 |
| `-7 // 2` | `-4` | -3.5 向更小的整数方向取整 |
| `int(-7 / 2)` | `-3` | 向零截断，与向下取整不同 |
| `7.0 // 2` | `3.0` | 使用内置浮点数参与 `//` 时，结果是浮点数 |

> [!warning] // 不等于“舍弃小数”
> 正数例子容易让两者看起来相同，负数才能体现差异。`//` 也不保证结果类型是 `int`。

补充两个常用运算：

```python
print(7 % 2)   # 1：取余
print(2 ** 3)  # 8：乘方
```

### 了解即可：列表的 += 可能直接修改原对象

```python
a = [1]
b = a
a += [2]
print(b)  # [1, 2]：列表被原地扩展

a = [1]
b = a
a = a + [2]
print(b)  # [1]：a 重新绑定到拼接后新建的列表
```

现在先记住“不能把所有类型的增强赋值都机械替换成普通赋值”，学习列表时再回看。

## 4. 解包赋值：把元素分给变量

```python
a, b, c = 10, 20, 30
print(a, b, c)  # 10 20 30

a, b = b, a
print(a, b)     # 20 10：交换变量绑定
```

右侧先求值，再进行左侧赋值，因此交换时不必自己设置临时变量。

```python
# a, b = 10, 20, 30  # ValueError：目标数量不匹配

first, *rest = [10, 20, 30]
print(first)  # 10
print(rest)   # [20, 30]：带星号的目标收集剩余元素
```

和 JS 解构相似，但 Python 普通解包要求元素数量匹配；带星号时才可收集剩余元素。可迭代对象的概念可以后续再展开。

## 5. 比较值与判断身份

```python
a = [1, 2]
b = [1, 2]
c = a

print(a == b)  # True：列表内容相等
print(a is b)  # False：两个不同的列表对象
print(a is c)  # True：同一个列表对象
```

`is` 判断对象身份，不是 Python 版本的 JS `===`。JS 中两个独立数组使用 `===` 比较是 `false`，而 Python 列表的 `==` 会比较内容。

> [!warning] 不要用 is 比较数字或字符串的值
> 对象复用等实现细节可能让某些小例子“碰巧成功”。比较值用 `==`；常见的身份判断用途是 `value is None` 或 `value is not None`。`None` 表示没有值，与 JS 的 `null` 在一些场景中类似。

Python 也支持链式比较：

```python
age = 18
print(0 <= age < 120)  # True：类似 JS 的 0 <= age && age < 120
```

JS 的 `==` 有自己的隐式转换规则，所以不能说所有比较规则都与 Python 相同。

## 6. 布尔运算：and、or、not

| Python | JS 对照 | 含义 |
| --- | --- | --- |
| `and` | `&&` | 左侧为假时停止，否则计算右侧 |
| `or` | `\|\|` | 左侧为真时停止，否则计算右侧 |
| `not` | `!` | 对真假值取反，返回 bool |

```python
print(True and False)  # False
print(True or False)   # True
print(not True)        # False

print('' or '默认名称')  # 默认名称
print('Python' and 123) # 123
```

`and`、`or` 会短路，也会返回某个操作数，不保证返回 `True` 或 `False`。这一点和 JS 的 `&&`、`||` 相似。

> [!warning] Python 与 JS 对“空容器”的判断不同
> Python 中 `None`、`False`、数值零、空字符串以及空列表、空字典、空集合等都为假。
> JS 的空数组 `[]`、空对象 `{}` 却为真，不能直接迁移这一经验。

```python
print(bool('False'))  # True：它是非空字符串
print(bool('0'))      # True：它也是非空字符串
print(bool([]))       # False
print(0 or 100)       # 100：注意，合法值 0 也会被当成假值
```

## 7. 成员判断：in 与 not in

`in`、`not in` 是成员运算符，结果是布尔值。它们常出现在条件中，但应与 `and`、`or`、`not` 分开理解。

```python
print('py' in 'python')          # True：子字符串
print(2 in [1, 2, 3])            # True：列表元素
print(4 not in [1, 2, 3])        # True
print('name' in {'name': '张三'})  # True：字典默认检查键
print('张三' in {'name': '张三'})  # False：不是检查值
```

> [!tip] JS 对照
> 判断数组是否包含某个值，Python 的 `2 in [1, 2, 3]` 更接近 JS 的 `[1, 2, 3].includes(2)`。
> JS 的 `in` 判断属性是否存在，例如 `0 in ['a']` 检查索引属性，不是检查数组是否包含数值 0。

## 8. 位运算：先掌握正整数案例

Python 内置整数支持位运算，可以按二进制位来理解；并不是先把数字变成二进制字符串再运算。

```text
6 的二进制：110
3 的二进制：011
```

| 运算符 | 规则 | 例子 |
| --- | --- | --- |
| `&` 按位与 | 对应两位都是 1 才为 1 | `6 & 3` → `2`，即 `010` |
| `\|` 按位或 | 对应两位任一为 1 就为 1 | `6 \| 3` → `7`，即 `111` |
| `^` 按位异或 | 对应两位不同时为 1 | `6 ^ 3` → `5`，即 `101` |
| `~` 按位取反 | 对整数有 `~x == -x - 1` | `~6` → `-7` |
| `<<` 左移 | 左移 n 位相当于乘以 `2 ** n` | `4 << 2` → `16` |
| `>>` 右移 | 右移 n 位相当于整除 `2 ** n` | `9 >> 1` → `4` |

> [!warning] 修正原笔记的三个地方
> - `|` 的规则是“任一位为 1，结果就为 1”；两位都是 0 时结果才是 0。
> - Python 整数没有固定的 32 位宽度，左移不会按固定宽度自动丢弃高位。
> - “右移高位补 0”只适合某些非负数的直观说明；负数右移应按向下整除理解，例如 `-3 >> 1` 得到 `-2`。

JS 普通 `number` 的 `&`、`|`、`^`、`~`、`<<`、`>>` 使用 32 位整数规则，不能据此推导 Python 的大整数位运算。JS `BigInt` 有不同规则，此处先不展开。

> [!tip] 学习优先级
> 当前优先掌握输入、赋值、比较和布尔运算。位运算先会看简单案例，后续遇到权限标记等实际需求再深入。`&`、`|` 和 `and`、`or` 也不能随意互换。

## 9. 本课常见运算符优先级

以下从高到低列出本课常见项；不是 Python 所有表达式的完整清单。

| 顺序 | 运算符 |
| --- | --- |
| 高 | `**` |
| ↓ | 一元 `+`、一元 `-`、`~` |
| ↓ | `*`、`/`、`//`、`%` |
| ↓ | `+`、`-` |
| ↓ | `<<`、`>>` |
| ↓ | `&` |
| ↓ | `^` |
| ↓ | `\|` |
| ↓ | `<`、`<=`、`>`、`>=`、`==`、`!=`、`in`、`not in`、`is`、`is not` |
| ↓ | `not` |
| ↓ | `and` |
| 低 | `or` |

```python
print(2 + 3 * 4)       # 14
print((2 + 3) * 4)     # 20
print(True or False and False)  # True：先计算 and
print(-2 ** 2)         # -4：相当于 -(2 ** 2)
print((-2) ** 2)       # 4
print(2 ** -2)         # 0.25：幂运算的右侧允许一元负号
```

`**` 连续出现时从右结合：`2 ** 3 ** 2` 等于 `2 ** (3 ** 2)`，结果为 `512`。

普通 `=` 是赋值语句的一部分，不应当作最低优先级的表达式运算符加入这张表。遇到复杂条件时主动加括号表达意图，比依赖读者背诵优先级更清楚。

## 10. 变式练习

先预测结果，再运行验证。假设输入的文本是 `'8'`：

```python
text = '8'
print(text * 2)
print(int(text) // 3)
print(-8 // 3)

print([] or '备用值')
print('0' and 99)

a = b = [1]
a += [2]
print(a == b, a is b)

print('x' in {'x': 0})
print(4 | 1)
```

> [!question]- 展开查看答案与原因
> - `88`，类型为 `str`：字符串重复。
> - `2`，类型为 `int`：先转为整数，再向下整除。
> - `-3`，类型为 `int`：-8/3 向下取整，不是向零截断。
> - `'备用值'`：空列表为假，`or` 返回右侧操作数。
> - `99`：非空字符串 `'0'` 为真，`and` 返回右侧操作数。
> - `True True`：`+=` 原地扩展列表，两个名字仍指向同一对象。
> - `True`：字典成员判断检查键。
> - `5`：二进制 `100` 与 `001` 按位或得到 `101`。
