# Python 学习路线与助教约定

记录日期：2026-10-15

文件前缀：`ai-ta-`，表示 AI 助教整理的笔记。

## 你的起点与目标

- 已有 JS、TS、Vue、React、uniapp 开发经验；Python 刚开始，已经安装环境并运行变量、数据类型等案例。
- 以现有课程为主，助教负责答疑、纠错、联系前端知识和提供适量变式练习。
- 主线：Python 基础 → Python 后端 → 结合已有前端能力开发 AI 应用。
- 兴趣支线：爬虫与数据采集。
- 半年目标：独立完成一个可演示、可部署、能够解释设计和排查问题的 AI 全栈项目。它是作品与实践目标，不等于保证就业或达到资深水平。
- 不规定每日时长，按掌握程度推进。下面月份是顺序参考，进度不足时缩小项目范围，不跳过基础。

## 自动化脚本是什么

自动化脚本就是把一组原本需要手动执行的步骤写成程序，让计算机按规则执行。脚本可以手动运行，也可以交给定时任务运行。

| 用途 | 例子 |
| --- | --- |
| 文件处理 | 批量重命名图片、整理下载文件、检查缺失资源 |
| 数据处理 | 读取 CSV、清洗数据、生成报表 |
| 接口操作 | 批量调用接口、检查服务状态 |
| 自动化测试 | 自动请求接口并断言结果，或操作网页验证功能 |
| 爬虫 | 请求页面、提取公开数据、保存结果 |
| 开发辅助 | 整理日志、检查配置、生成重复代码 |

测试和爬虫都可以用脚本实现。它们分别关注“验证功能”和“获取数据”；自动化描述的是“让步骤自动执行”，三者并不是互斥分类。你以前写过的 Node.js 批处理脚本也属于自动化脚本。

## 六个月参考路线

### 阶段一：基础语法，约第 1 个月

跟课程学习变量与对象、基础类型、类型转换、字符串、条件、循环、列表、元组、字典、集合、函数与作用域。

重点对照 JS：缩进、相等比较、真假值、可变对象与共享引用、函数参数。类比用来理解，具体规则以 Python 为准。

小成果：命令行待办清单，先用列表保存数据。

通过标准：不照抄课程，能够用函数实现添加、查询、删除，并解释数据怎样变化。

### 阶段二：写出实用小程序，约第 2 个月

学习模块与包、异常、文件读写、JSON、路径处理、类的基础、虚拟环境与依赖安装。理解类型标注的用途，逐步接触日志、调试和基础测试。

小成果：把待办清单保存到 JSON 文件；另做一个文件整理脚本，先提供预览，再执行移动。

通过标准：能够拆分多个文件，处理文件不存在或格式错误，并在独立环境里运行项目。

### 阶段三：HTTP 与爬虫入门，约第 3 个月

复习 HTTP 请求、响应、状态码、请求头、Cookie；学习 Python 发请求、处理 JSON、解析 HTML、分页、超时、有限重试与数据保存。

先处理接口数据和静态 HTML，再按实际需要学习浏览器自动化。了解站点访问规则、请求频率与数据使用边界。

小成果：采集允许访问的公开练习页面，保存为 CSV 或 SQLite 数据。

通过标准：能区分请求失败、解析失败、数据为空，并避免重复保存。爬虫可以作为支线穿插学习，不必深入后才开始后端。

### 阶段四：Python 后端，约第 4 个月

建议先集中使用 FastAPI，学习路由、请求参数、数据校验、统一错误响应、环境变量与跨域。补充 SQL、表关系、CRUD、事务与数据库迁移，再学习登录认证、权限和文件上传。

数据库可从 SQLite 起步，部署项目时再按需要迁移到 PostgreSQL。理解同步与异步的差别，避免把所有函数都机械改成 `async`。

小成果：使用熟悉的 Vue 或 React，完成带登录功能的笔记管理应用。

通过标准：前后端可以联调，用户只能访问自己的笔记，输入错误能得到明确反馈，重启服务后数据仍在。

### 阶段五：接入 AI 能力，约第 5 个月

先直接调用一个模型服务，理解消息、提示词、Token、流式输出、超时、错误处理和费用记录。API 密钥保存在后端。

先实现单轮问答，再增加会话保存和流式展示；基础通畅后再做结构化输出、工具调用或 RAG。RAG 指先检索相关资料，再把资料提供给模型生成回答，不等于重新训练模型。

小成果：在笔记应用里增加 AI 总结与问答功能。

通过标准：能处理模型调用失败、限制请求规模，并解释回答从哪里来。先用固定样例检查效果，再根据需要引入框架。

### 阶段六：完成并部署项目，约第 6 个月

把已有功能整理成“个人学习知识库”：登录 → 写入或导入笔记 → 检索 → AI 总结与问答 → 保存历史。

第一版只做文本笔记和问答；文档上传、带来源的 RAG、爬虫导入按时间增加。

补齐关键接口测试、权限检查、日志、部署配置和 README。根据部署环境学习 Linux、进程运行、反向代理、HTTPS；需要容器时再学习 Docker。

通过标准：别人能按文档启动或访问项目；你能独立演示、修改功能，并解释一次真实问题的定位过程。保留实际开发记录，不把个人项目写成工作经历。

## 当前先做什么

继续学习当前课程的数据类型，再进入条件、循环、容器和函数。每学完一组知识，用一个十几行到几十行的小练习验证，不用等待所有课程结束。

暂时无需同时学习多个后端框架、微服务、模型训练或复杂 Agent 框架。遇到具体需求再补充，避免主线被工具清单淹没。

## 助教工作约定

1. 默认回答顺序：直接结论 → 最小可运行例子 → 原因 → 必要的 JS/TS 对照 → 一个适量的变式或反例。简单问题简答，不强行套全流程。
2. 不默认你掌握 Python；已有编程知识能复用时不重复铺垫。
3. 你贴代码时，先解释现象和原因，再给最小修改。没有运行验证时明确说明。
4. 练习默认先给提示；你要求完整答案时直接提供。
5. 发现课程或笔记中的误解，明确指出，并区分语言规则、实现细节与个人风格。
6. 教材优先选择讲解扎实的内容；涉及安装、框架和 API 时检查版本适用性，不用资料年代判断质量。
7. 原始课程案例在 `python-learn1`，你自己的笔记在 `note`，案例素材在 `store`。助教新增笔记统一放在 `note/ai-ta-*.md`，不擅自重写原始笔记。
8. 重要疑问按主题整理，避免每句聊天都生成一个文件。新增练习或修改案例时尊重当前请求范围。
