## 赋值运算符

### 链式赋值
从右到左连续复制，指向的是同一个内存。和`js`类似的效果，但是我不清楚`js`是否是相同的内存（应该是）。

#### 纠错
从右到左连续复制 -> “右侧表达式求值一次，再绑定到多个目标”

```python
a=b=c=10
print(a, id(a)) # 10 140720426542640
print(b, id(b)) # 10 140720426542640
print(c, id(c)) # 10 140720426542640
```

### `[type]=` 运算符赋值
和`js`一样，好像多了`//=`除且只保留整数部分内容的操作。

```python
a+=10
print(a) # 20
a*=3
print(a) # 60
a+=7
print(a)
a/=2 # 32.5
# a//=2 # 32 会舍弃小数点后面的内容
print(a)
```

### 系列解包赋值
类似于解构赋值相同的用法。

```python
a,b,c=10,20,30
print(a, b, c) # 10 20 30
```

## 比较运算符
`>, <, >=, <=, ==, !=`，这类运算符和`js`一样。除此还有`is，is not`
`==` 比较值，`is` 比较标识（id）。

## 布尔运算符
`and, or, not, in, not in`，大概对应`js`中的`||, &&, !`, `in, not in` 标识是否包含。

## 位运算符
将数据转换成二进制进行运算分别有`&, |, <<, >>`。也许和`js`一样。
`&`: 对应数位都是1，结果数位才是1，否则0。
`|`: 对应数位都是0，结果数位才是1，否则0。
`<<`: 高位移除舍弃，低位补0。`4<<1`，移动**1**位相当于乘以**2**。`<<1, <<2`后的数字是可以修改的。
`>>`: 低位移除舍弃，高位补0。`4>>1`，移动**1**位相当于除以**2**。

## 运算符优先级
算术运算符 > 位运算符 > 比较运算符 > 布尔运算符
`** -> [*, /, //, %] -> [+, -] -> [<<, >>] -> & -> | -> [>, <, >=, <=, ==, !=] -> and -> or -> =`

## 为 False 的布尔值
以下内容为`False`布尔值，其余的都为`True`。

```python
print(bool(False)) # False
print(bool(0)) # False
print(bool(0.0)) # False
print(bool(None)) # False
print(bool('')) # False
print(bool("")) # False
# 空列表
print(bool([])) # False
print(bool(list())) # False
# 空元组
print(bool(())) # False
print(bool(tuple())) # False
# 空字典
print(bool({})) # False
print(bool(dict())) # False
# 空集合
print(bool(set())) # False
```
