## 数据类型
`int`, `float`, `bool`, `str`。

`int` 整数类型有正数负数，可以表示为二进制、十进制（默认）、八进制、十六进制。

`float` 浮点类型小数类型，注意以下案例：
```python
# 关键在于：Decimal 要解决精度问题，必须用字符串构造，而不是用 float 构造。
from decimal import Decimal

# ① 纯 float —— 不精确
print(1.1 + 2.2) # 3.3000000000000003

# ② float 构造 Decimal —— 照样不精确（只是把误差精确展开了）
print(Decimal(1.1) + Decimal(2.2)) # 3.300000000000000266453525910

# ③ 字符串构造 Decimal —— 精确！
print(Decimal("1.1") + Decimal("2.2")) # 3.3
```

`bool` 布尔类型和 `JS` 一样可以进行数学运算

`str` 字符串类型有单引号、双引号、三引号，三引号（"""）类似于``字符串模板允许进行换行。

## 类型转换
在python中，不同的数据类型通过`+`符号拼接时是会提示报错的。这个时候只能通过转换类型拼接。
`int`、`float`、`str`。

```python
# TypeError: can only concatenate str (not "int") to str
# print('名字：'+name+'年龄'+age+'。')
print('名字：'+name+'年龄'+str(age)+'。')
```

### 疑问？
在`JS`中是允许拼接的（这个和弱类型有关系吗？）
解答：
我可能混淆了“动态类型、静态类型”和“强类型、弱类型”的含义。
“动和静”区别在运行时检查还是运行前检查。
“强和弱”区别在于是否允许类型混用和隐式转换的限制。

| 概念 | 关注什么 | Python 与 JS |
| --- | --- | --- |
| 动态类型 / 静态类型 | 类型主要在运行时还是运行前检查 | Python、JS 都属于动态类型语言 |
| 强类型 / 弱类型 | 对不同类型混用和隐式转换的限制 | Python 通常称为强类型，JS 通常称为弱类型 |

### 题目
有意思的是字符串的*是重复的意思

```python
print('3' * 2) # 33
print(3 + True) # 4
```

这里需要区分：'3' * 2 没有把字符串转换成数字，而是在执行 Python 支持的“字符串重复”操作。
```python
print(3 * 2)      # 6：数字 × 数字，做乘法
print('3' * 2)    # 33：字符串 × 整数，重复字符串
print('Hi' * 3)   # HiHiHi
```
